# Датасет диктовок ИИ-парсера

> ⚠️ ЧЕРНОВИК: 10 примеров написаны разработчиком под типовой шаблон
> «кондиционерщик» из сида. Владелец проекта заменит/дополнит их
> 25–30 реальными диктовками с объектов — это эталон для тестов
> и источник few-shot примеров промпта.

Формат: заголовок `## Диктовка N`, строка `Текст:` и JSON-блок с ожидаемым
разбором. Названия позиций и комплектов — дословно из сид-шаблона.
Первые 4 диктовки также подставляются в промпт как few-shot примеры.

## Диктовка 1
Текст: монтаж девятки, трасса 4 метра, штроба бетон 2 метра, помпа

```json
{
  "items": [
    {"name": "Монтаж сплит-системы 09", "qty": 1},
    {"name": "Трасса фреоновая", "qty": 4},
    {"name": "Штроба (бетон)", "qty": 2},
    {"name": "Помпа дренажная", "qty": 1}
  ],
  "bundles": [],
  "unrecognized": []
}
```
